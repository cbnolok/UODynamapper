# Keybindings

This document lists the keyboard shortcuts used in UODynamapper.

## Window Management
| Key | Action |
|-----|--------|
| `F11` | Toggle Fullscreen / Windowed mode |
| `Alt + Enter` | Toggle Fullscreen / Windowed mode |

## Player Movement
| Key | Action |
|-----|--------|
| `W` | Move North-West (UO Up) |
| `S` | Move South-East (UO Down) |
| `A` | Move South-West (UO Left) |
| `D` | Move North-East (UO Right) |
| `PageUp` | Increase Height / Altitude (Configurable) |
| `PageDown` | Decrease Height / Altitude (Configurable) |


## Application
| Key | Action |
|-----|--------|
| `Ctrl + G` | Open Teleport Dialog (Planned) |
| `Esc` | Close Dialogs / Menu |
| `Scroll Wheel` | Zoom In / Out |
| `+` / `-` | Zoom In / Out |
| `Alt + Click + Drag` | Pan camera (if applicable) |

## Free Camera Mode (F2 -> Window -> Free Camera)
| Key | Action |
|-----|--------|
| `Arrow Keys` | Pan Camera (Longitudinal/Lateral) |
| `Shift + Arrow Up/Dn` | Change Camera Altitude |
| `R-Shift + W / S` | Pitch (Local X-Axis) |
| `R-Shift + A / D` | Yaw (Local Y-Axis) |
| `R-Shift + Q / E` | Roll (Local Z-Axis) |

## Developer & Settings
| Key | Action | Default |
|-----|--------|---------|
| `F1` | Keybindings Help | `F1` (Configurable) |
| `F2` | Options Menu | `F2` (Configurable) |
| `F3` | Terrain Shader Controls | `F3` (Configurable) |

> [!NOTE]
> Keybindings are configurable! You can change them by editing the `assets/keybindings.toml` file.
