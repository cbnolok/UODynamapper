## Gemini Notes

- Use `ENGINEERING.md` as the primary reference for architecture constraints, build commands, and engineering discipline.
- For deeper technical specifications, consult `docs/dev_wiki/`.
- When making visual changes to `dynamapper/`, test all three rendering presets (Classic 2D, Enhanced Classic, KR-like) before reporting the task complete.
- Do not run `cargo fmt` or `cargo clippy` — see ENGINEERING.md for the formatting policy.
